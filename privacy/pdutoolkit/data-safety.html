Rack Power Toolkit — Google Play Data Safety Declaration

This page is the source of truth for the Data Safety section of the Rack Power Toolkit Play Store listing. Copy the values below into the Play Console when prompted.

Data collection & sharing summary

QuestionAnswer
Does the app collect or share any user data?Yes (stored on-device only; not transmitted)
Is all of the user data collected by the app encrypted in transit?N/A — no data leaves the device (the app requests no network permission)
Do you provide a way for users to request that their data be deleted?Yes — uninstalling the app removes all app-local data

Data types collected

Category / TypeCollectedSharedEphemeralRequired / OptionalPurposes
App activity → App interactions (power inputs, saved budgets, disclaimer state) YesNoNoRequiredApp functionality
Files and docs → Files (user-generated CSV/PDF budget files) YesNoNoOptionalApp functionality

Note: "Collected" in Google's terms here means "the app records this on device." None of it is sent to any server; budget files leave the device only through a share the user initiates.

Security practices

  • Data is encrypted in transit — N/A (no transmission; zero permissions)
  • You can request data be deleted — users can uninstall to remove all data
  • Committed to Play Families Policy — N/A (general-audience utility, not directed at children)
  • Independent security review — No (solo developer)

Third-party SDKs

Rack Power Toolkit integrates no analytics, advertising, tracking, crash-reporting, or identity SDKs.
