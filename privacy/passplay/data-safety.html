PassPlay — Google Play Data Safety Declaration

This page is the source of truth for the Data Safety section of the PassPlay Play Store listing. Copy the values below into the Play Console when prompted.

Data collection & sharing summary

QuestionAnswer
Does the app collect or share any user data?No
Is all of the user data collected by the app encrypted in transit?N/A — no data collected
Do you provide a way for users to request that their data be deleted?N/A — nothing retained (uninstalling removes the sound setting; names are RAM-only)

Data types collected

None. No category is ticked: player names live in RAM for the session only, and the sound toggle is a local setting, not user data. Deck links, QR codes, and scoreboard images leave the device only through user-initiated share/clipboard actions.

Security practices

  • Data is encrypted in transit — N/A (no transmission)
  • App requests zero Android permissions — verified by tool/check_permissions.sh
  • No third-party SDK transmits data — verified by tool/check_deps.sh and tool/ban_http_imports.sh
