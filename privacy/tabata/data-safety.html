T-timer — Google Play Data Safety Declaration

This page is the source of truth for the Data Safety section of the T-timer Play Store listing. Copy the values below into the Play Console when prompted.

Data collection & sharing summary

QuestionAnswer
Does the app collect or share any user data?Yes (only when the user opts in to analytics)
Is all of the user data collected by the app encrypted in transit?Yes — Firebase SDK uses TLS for all network requests
Do you provide a way for users to request that their data be deleted?Yes — opt out any time (More → Analytics toggle); uninstall removes all local data

Data types collected

Category / TypeCollectedSharedEphemeralRequired / OptionalPurposes
App activity → App interactions (workout started/completed, phase changes, settings changes, feedback opened/submitted counts) YesNoNoOptionalAnalytics

All other categories (Location, Personal info, Financial info, Health and fitness, Messages, Photos, Audio, Files, Calendar, Contacts, Device IDs, Web browsing): not collected. Feedback text and optional email stay on-device only and are never transmitted.

Security practices

  • Data is encrypted in transit — Yes
  • You can request data be deleted — yes, see policy
  • Independent security review — No (solo developer, open-source app)

Third-party SDKs

T-timer integrates Firebase Analytics (Google LLC) for anonymous usage analytics, active only when the user opts in. No advertising, tracking, crash-reporting, or identity SDKs.
